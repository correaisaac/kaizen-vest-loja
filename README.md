# Kai Zen Vest — Loja

Catálogo com carrinho que fecha o pedido pelo WhatsApp. Publicado via GitHub Pages e incorporado no Google Sites.

- Número que recebe os pedidos: constante `WHATSAPP` no início do `<script>` em `index.html`.
- Produtos: array `PRODUCTS` em `index.html` (cópia em `products.json`); fotos em `img/<CÓDIGO>.jpg`.
